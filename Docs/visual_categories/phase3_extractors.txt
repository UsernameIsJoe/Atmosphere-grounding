PURPOSE
-------
Assign how each subtype family is measured from an image. One ontology;
multiple tools. Still NO atmosphere lexicon bindings.

LOCKED TOOL STACK
-----------------
  dino     Grounding DINO — open-vocab localized boxes/phrases
  seg      Semantic segmentation — pixel / view-factor fractions
  siglip   SigLIP — soft image–phrase similarity
  metric   Classical image statistics — contrast, brightness, entropy, edges

Hybrid allowed. Primary extractor is listed first.


WHY MULTI-TOOL (decision reminder)
----------------------------------
Grounding DINO answers “is this nouny thing present, and where?”
It does NOT reliably answer “how open is the space?” or “how high is
visual contrast?” Those are global properties → seg / metric / soft
SigLIP phrases. Streetscape literature already splits object-like content
from sky/building/tree fractions (Middel et al. 2019).


ASSIGNMENT RULES
----------------
1. If a human can point to an instance → prefer dino.
2. If the meaning is “how much of the view” → prefer seg.
3. If the meaning is a global photometric/structural property → metric.
4. If the cue is abstract/linguistic but useful → siglip (soft).
5. Fixtures vs qualities stay split (e.g. light_fixture vs brightness_level).

SUPPORT FOR EXTRACTOR CHOICES
-----------------------------
DINO for discrete nouns:
  Matches open-vocabulary grounded detection practice; aligns with this
  project’s existing grounding_dino_model usage for object vocabularies.

SEG for spatial amounts:
  Middel et al. (2019) Landscape & Urban Planning — sky/trees/buildings/
  impervious/pervious spherical fractions from street imagery.
  SVF/TVF/BVF GSV+deep learning literature for openness/enclosure proxies.

METRIC for composition:
  Edge density / complexity: Machado et al., computerized visual complexity.
  Color entropy / lightness statistics: aesthetics image-property toolboxes
  (Behavior Research Methods 2025 Aesthetics Toolbox);
  HortTechnology 2015 color information entropy & preference.

SIGLIP for soft/abstract cues:
  Already in pipeline for phrase–image matching; appropriate when the cue
  is linguistic/scene-level (“well-lit path”, “group of people gathering”,
  “open plaza”) rather than a tight boxable noun.

Böhme (1993; 2017): light as generator → motivates BOTH fixture detection
and photometric brightness, not fixtures alone.


FEATURE-SPACE NOTE (for later verification design)
--------------------------------------------------
An image vector can concatenate:
  - DINO: presence/count/confidence/box stats per family phrases
  - SEG: fractions per spatial_structure (+ related covers)
  - METRIC: scalar contrast/brightness/complexity
  - SIGLIP: soft scores for designated soft families
Atmosphere weights (multi-label per image) remain a SEPARATE head/output
discovered/scored from data — not encoded in this ontology.


IMPLEMENTATION HINTS (non-binding)
----------------------------------
- Segmentation model: Cityscapes/ADE20K-class model (e.g. Mask2Former /
  DeepLab-style) — exact checkpoint chosen at implementation time.
- Metrics: luminance std / Michelson contrast; palette entropy; Canny edge
  density — exact formulas in a later metrics note.
- Soft SigLIP phrases: curated per soft family when phrase lists are built.
- DINO phrase lists: next documentation/config step after this phase.
