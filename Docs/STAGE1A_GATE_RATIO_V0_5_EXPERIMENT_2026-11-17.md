# Experimental gate relevance proportion v0.5 — 2026-11-17

Research experiment only; the accepted v0.4 gate remains unchanged. Use all 36 original regression reviews, both KEEP and REJECT, not just the emotion-test subset. Use the existing gate model Qwen3:8B, not a new model comparison. No emotion extraction or E/T classification is run.

One call per whole review labels every source-exact coarse clause unit in context. The deterministic splitter separates sentence-ending punctuation, newlines, semicolons, and comma-following but/yet/however; it is an operational approximation, not a complete grammatical clause parser. It preserves every non-whitespace source character and offsets. Attached labels are relevant, other or boilerplate. Generic praise and event/service narratives remain substantive OTHER assertions rather than disappearing from the denominator. Only content-free greetings, standalone thanks/recommendations, and empty social filler can be boilerplate.

Primary ratio = relevant units / (relevant + other units). A zero substantive denominator is REJECT. KEEP requires at least one relevant unit and ratio >= threshold, inclusively. Compare fixed thresholds 25%, 50%, 75% from the same labels. Also report ANY-relevant control to distinguish the threshold effect from differences caused by changing the labeling prompt. Report a secondary word-weighted ratio using the same labels, since unit lengths differ; this is sensitivity analysis, not a second model run.

No previous verdicts, researcher labels, threshold values, or examples from the cohort enter the model input. Full original review and all numbered units are supplied in every request. The prompt implements the existing place-level relevance concept; this experiment does not introduce a blanket wedding/event exclusion. Unclear or context-bound descriptions receive OTHER unless a substantive independent place attribute is identifiable.

Archive all input units, raw outputs, validation errors, digests, settings and per-unit reasons. No semantic retries, no truncation of the review cohort, and no adoption of a threshold without reviewing new rejections. Only selected previous human judgments exist; report case outcomes rather than full accuracy. These development reviews are not an independent holdout. The old gate manifest did not record a weight digest; record the installed digest now without claiming a verified weight match to that old run.
